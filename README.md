# Practice_oop

Практические работы по курсу **«Объектно-ориентированное программирование»** на C++.

Репозиторий — набор отдельных практических заданий (`practice_1` … `practice_10`), каждое в своей папке, со сборкой через CMake.

## Стек

- **Язык:** C++
- **Сборка:** CMake (`CMakeLists.txt`, `CMakePresets.json`)
- **Менеджер зависимостей:** vcpkg (`vcpkg.json`, `vcpkg-configuration.json`)
- **IDE:** VS Code (конфиги в `.vscode/`)

## Структура и темы практик

| Папка | Тема / что реализовано |
|---|---|
| `practice_1` | *базовая компиляция* |
| `practice_2` | *работа со стандартной библиотекой std* |
| `practice_3` | *решение логических задач* |
| `practice_4` | *класс дроби* |
| `practice_5` | *класс дроби с перегрузкой операторов* |
| `practice_6` | *кастомный класс String* |
| `practice_7` | *классы сериализации* |
| `practice_8` | *кастомный класс контейнеров* |
| `practice_9` | *проект с использованием vcpkg* |
| `practice_10` | *использование SFML* |

## Зависимости проектов

Зависимости подтягиваются через vcpkg согласно `vcpkg.json` в корне репозитория.

## Контекст

Это учебные задания курса ООП, выполненные последовательно в течение семестра — каждая папка закрывает отдельную тему, без единой сквозной архитектуры между практиками (это не один общий проект, а набор независимых упражнений).
